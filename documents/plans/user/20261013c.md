# kaseifu CLIデバッグシナリオ追加指示書 v1.2

**Repository:** https://github.com/smapira/kaseifu  
**基準文書:** kaseifu デバッグシナリオ設計書 v1.1  
**追加範囲:** S21〜S28  
**作業内容:** シナリオ設計のみ  
**実装・テスト実行:** 対象外

## 1. 目的

既存のS01〜S20で不足しているCLIコマンドの検証シナリオを追加し、全コマンドに明示的なデバッグシナリオを割り当てる。

今回の追加では、次の観点を重視する。

- CLIとしての入出力契約
- 引数・オプションの組み合わせ
- 正常系・異常系・境界値
- コマンド実行による副作用
- エラー処理と終了コード
- コマンド間の整合性

既存シナリオとの重複は避け、必要に応じて既存シナリオIDを相互参照する。

## 3. S21 — scan

**テストの問い：** 指定したディレクトリを正しく走査し、対象ファイルの集合と結果を一貫して出力できるか。

| ケース | 入力条件 | 期待結果 |
|---|---|---|
| S21-01 | 通常のディレクトリ | 対象ファイルが走査される |
| S21-02 | 空ディレクトリ | 正常な空結果 |
| S21-03 | 存在しないパス | 明確なエラー |
| S21-04 | ファイルを指定 | CLI仕様に沿った処理または拒否 |
| S21-05 | ネストしたディレクトリ | 再帰オプションの仕様に一致 |
| S21-06 | 隠しファイル | 除外・包含ルールに一致 |
| S21-07 | シンボリックリンク | 循環や意図しない走査を防ぐ |
| S21-08 | 権限不足 | エラーを識別できる |
| S21-09 | 大量ファイル | 件数と処理対象の整合性が保たれる |
| S21-10 | 走査中にファイル削除 | 異常終了や不正結果を防ぐ |

再帰、フィルタ、件数制限などのオプションは実装を確認し、存在するものだけを正式なテスト対象にすること。

## 11. CLI共通の横断シナリオ

S21〜S28に加え、すべての公開コマンドを対象として以下を設計する。

| ID | 検証対象 |
|---|---|
| C01 | `--help` |
| C02 | `--version`（対応する階層） |
| C03 | 必須引数の欠落 |
| C04 | 未知の引数・オプション |
| C05 | 不正な引数値 |
| C06 | 終了コード |
| C07 | stdout / stderrの分離 |
| C08 | Shell Tab Completion |
| C09 | 日本語・Unicodeパス |
| C10 | スペースを含むパス |
| C11 | Ctrl+Cなどの中断 |
| C12 | 秘密情報の非表示 |

サブコマンドを持つ場合は、各階層について適用可能な項目を設計すること。

## 13. 完了条件

- 公開CLIコマンド11種類すべてにシナリオが対応している。
- `auth`、`config`などのサブコマンドも対象としている。
- 正常系・異常系・境界値が整理されている。
- 各シナリオに反証可能な期待結果がある。
- 既存シナリオとの重複が明示されている。
- コマンド、サブコマンド、オプションの未カバー項目が可視化されている。
- 実装済み仕様と設計上の提案が区別されている。

**重要：本依頼ではシナリオの設計のみを行う。テストコードの作成、実行、既存ソースコードの変更は行わない。**
