## Code-determined facts (answers section 2 question)

- JevDecision::from_selection (src/models/decision.rs) builds MoveTo(id)/None only. Policy NOT applied.
- Policy = policy::decision::evaluate(&JevDecision) -> AutoMove/Review/Leave. Thresholds AUTO conf>=0.85 & margin>=0.40, REVIEW conf>=0.60 (match config/default.toml). plan::build_move_plan gates on same evaluate.
- Therefore action move_to D1 means "Jev picked D1", not a move permission. Rich view must NOT show MoveTo as execution; show Policy result separately.
- pipeline::decide_from_candidates validates probabilities then DROPS them (JevDecision keeps confidence/margin only). Ranking needs the distribution, so pipeline returns a ClassifyReport holding decision + probabilities + candidates + target in one pass (no re-run).
- main.rs ObservingJevIntegration prints raw debug to stdout, polluting Rich/JSON. Fix: stderr + --verbose only.
- inspect build() returns raw FileContext (no semantic signals, no file_type). signals/file_type come from normalize::normalize. Rich inspect runs build->normalize once, passes both to renderer.
- panel::frame is outer-frame only. Section divider (├─ TITLE ─┤) is a new extension.
- classify has no --all/--verbose; inspect has neither. Add both with discover-compatible meaning.
