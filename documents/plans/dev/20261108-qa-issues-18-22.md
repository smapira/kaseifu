`CARGO_TARGET_DIR=$HOME/.cache/...` the binary-level `v070_zero_config_p1_cli_test`

an excluded destination, so six of those older tests fail on the fixture path and
not on any behavior. Verified: they pass with the default target directory
(`cargo test --test v070_zero_config_p1_cli_test` → 6 passed).

## Residual risk

- The real Jev decision path was not exercised (no network in this environment).
  Every test that needs a decision uses `MockJevIntegration`/fakes, which is what
  the constraints require; the CLI checks above stop at the point where Jev would
  be called (LEAVE with no candidates never calls it).
- The benchmark indicators are fixture rankings, not a live index measurement
  (see plan §6). A live measurement needs the developer's own index, which the
  constraints forbid.
