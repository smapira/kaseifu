# v3.2 Image Metadata — BDD Plan (Phase 1-7, Phase 8 excluded)

Source of truth: `documents/plans/user/20261012.md`. Repo HEAD v0.3.0. Phase 8 weather excluded. Part B not implemented.

## BDD task breakdown (behavior units)

- T1 Spotlight PoC (Phase 1): `mdls` P0 9 attrs on real macOS images -> record which return values vs `(null)`. Evidence: this env shows `ContentCreationDate` only where indexed; pixel/datetime/GPS/camera `(null)` on test JPG/PNG (index-dependent, see §15 report).
- T2 Spotlight extraction (Phase 2): same file one `mdls` batch call -> `Evidence{SpotlightMeta}` per attr; `null`/missing/failure distinguished (skipped, no fabrication); failure never blocks classify.
- T3 EXIF fallback (Phase 3): JPEG/TIFF parsed internally (no new crate; kamadak-exif evaluated: JPEG/TIFF-only + new dep/license cost, HEIC still needs custom -> rejected per minimal-dep policy); HEIC box-scan best-effort; PNG/WebP reported unsupported; Spotlight-first, EXIF-only-on-missing, source recorded, no blind overwrite on conflict.
- T4 Normalization (Phase 4): `capture_time{value,timezone:null,source,timezone_known:false}` (no TZ guessing, mtime never as capture); `location{lat,lon,alt,source}` validated (-90..90/-180..180, NaN/Inf reject, partial GPS flagged, absent GPS ok); camera/dimensions typed; non-images omit `image_metadata` (JSON compat).
- T5 Jev integration (Phase 5): map only onto real `/v1/systemone` fields (`state.target.*` extensions + `state.semantic_signals` verbatim + `criteria` descriptions); no Rust fit-score; GPS/capture gated by privacy flags; mocked-server tests verify actual wire bytes.
- T6 Rich CLI (Phase 6): `inspect` adds CAPTURE METADATA + LOCATION sections, ASCII-only (`-` for missing), 3-layer (L1/L2/L3 verbose) preserved, NO_COLOR/non-TTY + JSON compat kept.
- T7 Privacy+config: `[metadata.image]/[metadata.privacy]/[metadata.weather]` in TOML resolver (CLI>Env>TOML+Keychain>Defaults), unknown keys rejected, GPS send default false, no GPS persistence, logs masked, `.env` search stays in resolver only.
- T8 Validation (Phase 7): `bash scripts/quality_check.sh` OVERALL PASS (fmt/clippy/test/complexity/baseline-gate), no new CC16+, regression (PDF/discover/policy/dry-run/move/journal/undo/JSON) green.
