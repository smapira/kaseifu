## 3. 指摘事項（重大度別）

### 🟡 MAJOR-1（修正済み・実装中に発見）: 計画のバンドル拡張子リストが `.photoslibrary` 系を捕れない

計画 §3.1 R1 は「`*.photoslibrary` は `.library` に含まれる」としていたが、文字列としては `photoslibrary` は `.library` で終わらない。ユニットテスト `excludes_app_managed_containers` が失敗して判明。

**対応**: `is_bundle_container` を「最後の `.` 以降（拡張子）が `library` で終わる」または「既知のパッケージ拡張子（`app`/`bundle`/`framework`/`pkg`/`plugin`/`xcodeproj`）に一致」に一般化。`Photos.photoslibrary`・`Music.tvlibrary` をテストで固定。誤って `mylibrary`（ドットなし）や `notes.app-backup` を除外しないことも固定。

### 🟡 MAJOR-2（計画外の追加）: OS 予約領域（`.Trash` 等）のネストを規則で閉じた

計画 §3.1 R3 は basename 限定のため `~/.Trash/old-album`（可視名）が残る残余を持っていた。組織化ツールがファイルをゴミ箱へ移すのは危害が大きいため、OS 予約名を **構成要素**として除外する規則を追加（`.Trash`/`.Trashes`/`.Spotlight-V100`/`.fseventsd`/`.DocumentRevisions-V100`/`.TemporaryItems`）。

**根拠**: 既存 `is_system_directory` が OS 領域名を持つ延長上にあり、個別パスの黒名单ではなく OS 命名規則。実機走査・実クエリで偽陽性 0 件。テストで固定済み。

### 🟢 MINOR-1: PDF 候補件数の変化（17 → 16）

`~/Library/Application Support/Code/User/workspaceStorage/<hash>/chatSessions` が R2 で除外されるため。**D1 `State Of Mind Labs` 1.00 は不変**で受入条件は満たす。意図的差分として記録。

### 🟢 MINOR-2: 検索段階と集約段階の 2 呼び出し点

同じ述語を 2 ヶ所で適用している。集約段階が権威（テスト・他呼び出し元を守る）、検索段階は採点前スキップ（性能 + debug 可読性）であり、結果の候補集合は同一。A/B 実測で候補 JSON が一致することを確認（差分は浮動小数末桁のみ）。コメントで意図を明記済み。
